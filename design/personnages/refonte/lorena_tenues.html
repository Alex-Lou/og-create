Lorena · tenues et états

LORENA est le nouveau nom d'Hermine, la navigatrice (dans les fichiers du jeu : aster). Même dessin que la refonte du sprite ; ici, ce qu'elle porte et dans quel état.

Ses états, du naufrage au propre

Le ciré jaune signal, de gauche à droite dans l'ordre de l'histoire. Chaque état règle ce qu'on voit sur elle : ourlet déchiré, recousu ou net ; sel, poussière et boue ; pièce de toile, corde, sparadrap, poignet bandé ; l'eau qui fonce le tissu.

À la taille du jeu

Prêt à intégrer

Même usage que les tenues d'hiver et de pluie de l'atelier : on habille Lorena, puis on la passe au kit comme n'importe quel maître.

const { frame, svg } = require('design/personnages/troupe');
const { habiller } = require('design/personnages/refonte/lorena_tenues');

// tenue : cire | ouvert | vareuse | chemise
// palette : signal | rouille | algue | quart | nuit | toile  (sinon celle de la tenue)
// état : propre | poussiere | rafistolee | rescapee | naufragee | trempee
const lorena = habiller('vareuse', 'nuit', 'rafistolee');
svg(frame(lorena, 'front', 'repos', 0, 'decidee'));
